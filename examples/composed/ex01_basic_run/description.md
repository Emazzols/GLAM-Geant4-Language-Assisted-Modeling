# ex01 – Basic run

## Purpose

This example demonstrates the simplest possible **complete simulation run**.

It combines geometry, source, and scoring into a single minimal and coherent
configuration.

Nothing is implicit.
Every component is explicitly defined.

---

## What this example demonstrates

- A valid end-to-end simulation
- Explicit geometry definition
- Explicit source configuration
- Explicit scoring configuration
- Name-based association between geometry and scoring

---

## What this example does NOT demonstrate

- Complex geometries
- Boolean solids
- Extended or isotropic sources
- Partial or multi-volume scoring

---

## Conceptual focus

Geometry, source, and scoring are **independent concepts**.

They are connected only through:
- explicit naming
- explicit user intent
