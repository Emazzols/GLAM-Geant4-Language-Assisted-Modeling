# exS06 – Particle type change in a point-like directional source

## Purpose

This example demonstrates that the particle type is an independent
parameter of the source.

It isolates the effect of changing the particle identity
without modifying any other source property.

## What this example demonstrates

- Change of particle type
- Monoenergetic emission
- Identical source geometry and direction

## What this example does NOT demonstrate

- Extended sources
- Angular distributions
- Energy changes
- Geometry definition
- Scoring configuration

No assumptions are made about geometry or scoring.
Both are intentionally left empty.

## Conceptual focus

Only one parameter changes: the particle type.

All other source properties remain identical to the baseline example.

This enforces the idea that changing the particle does not imply
changing energy, position, direction, or source geometry.

## Why this example exists

LLMs often implicitly associate specific behaviors
with specific particles.

This example teaches that particle identity is a standalone input
to the source definition.
