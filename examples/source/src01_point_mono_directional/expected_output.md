# Expected Output – exS01

## Qualitative behavior

- All primary particles originate from a single fixed point.
- All particles are emitted in the same direction.
- There is no angular spread.
- There is no spatial spread.
- All particles have identical energy.

## Observable consequences

- The particle flux is perfectly collimated.
- Any downstream interaction pattern depends only on geometry,
  not on the source configuration.
- Repeated runs produce identical emission characteristics.

## Diagnostic interpretation

If any of the following is observed:

- angular spread → the source is not directional
- spatial spread → the source is not point-like
- energy variation → the source is not monoenergetic

then the source configuration is incorrect.
