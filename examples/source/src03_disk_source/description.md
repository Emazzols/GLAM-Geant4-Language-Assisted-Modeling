# exS03 – Disk-shaped monoenergetic directional source

## Purpose

This example introduces spatial extension of a source.

It teaches how a source can occupy a finite planar region,
without introducing angular distributions.

## What this example demonstrates

- Disk-shaped (planar) source
- Finite spatial extent defined by a radius
- Directional emission
- Monoenergetic particles

## What this example does NOT demonstrate

- Isotropic emission
- Point-like sources
- Energy distributions
- Any geometry definition
- Any scoring configuration

No assumptions are made about geometry or scoring.
Both are intentionally left empty.

## Conceptual focus

The only new concept introduced here is spatial extent.

All particles:
- originate from different positions within a disk
- share the same emission direction

Spatial spread and angular spread are independent concepts.

## Why this example exists

This example teaches that source geometry
is independent from angular distribution.

It isolates spatial extension as a first-class concept.
