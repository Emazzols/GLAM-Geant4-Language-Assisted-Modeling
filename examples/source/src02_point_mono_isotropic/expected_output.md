# Expected Output – exS02

## Qualitative behavior

- All primary particles originate from a single fixed point.
- Particles are emitted uniformly in all directions.
- There is no preferred emission axis.
- All particles have identical energy.

## Observable consequences

- The particle flux is spherically symmetric around the source position.
- Downstream interaction patterns depend only on geometry,
  not on direction bias.
- No collimation or angular clustering is observed.

## Diagnostic interpretation

If any of the following is observed:

- preferred emission direction → the source is not isotropic
- spatial spread of origin → the source is not point-like
- energy variation → the source is not monoenergetic

then the source configuration is incorrect.
