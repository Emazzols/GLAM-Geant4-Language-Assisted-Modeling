# Expected Output – exS05

## Qualitative behavior

- All primary particles originate from a single fixed point.
- All particles propagate in the same direction.
- There is no angular or spatial spread.
- All particles have the same energy, higher than in the baseline example.

## Observable consequences

- Interaction patterns may change due to higher energy,
  but the emission geometry is unchanged.
- The particle flux remains perfectly collimated.
- Any downstream differences are attributable only to energy.

## Diagnostic interpretation

If any of the following is observed:

- change in emission direction → direction was modified incorrectly
- spatial spread → source is no longer point-like
- multiple energies → source is no longer monoenergetic

then the source configuration is incorrect.
