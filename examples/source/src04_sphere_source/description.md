# exS04 – Spherical monoenergetic directional source

## Purpose

This example introduces a volumetric extended source.

It teaches three-dimensional spatial extent of a source,
without introducing angular distributions.

## What this example demonstrates

- Spherical (volumetric) source
- Finite spatial extent defined by a radius
- Directional emission
- Monoenergetic particles

## What this example does NOT demonstrate

- Isotropic emission
- Point-like or planar sources
- Energy distributions
- Any geometry definition
- Any scoring configuration

No assumptions are made about geometry or scoring.
Both are intentionally left empty.

## Conceptual focus

A spherical source generates particles from random positions
inside a three-dimensional volume.

All particles:
- originate from different points within a sphere
- share the same emission direction

Spatial extent is purely volumetric and independent
from angular behavior.

## Why this example exists

This example completes the introduction of source geometry.

It teaches that:
- disk sources are extended in two dimensions
- sphere sources are extended in three dimensions

without changing any other source property.
