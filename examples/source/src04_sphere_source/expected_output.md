# Expected Output – exS04

## Qualitative behavior

- Primary vertices are distributed throughout a spherical volume.
- All particles propagate in the same direction.
- There is no angular spread.
- All particles have identical energy.

## Observable consequences

- The spatial distribution of primary vertices fills a sphere.
- The particle flux remains collimated.
- Any downstream spread is caused only by interactions with geometry,
  not by the source definition.

## Diagnostic interpretation

If any of the following is observed:

- planar or point-like origin → source geometry is incorrect
- angular spread → the source is not directional
- energy variation → the source is not monoenergetic

then the source configuration is incorrect.
